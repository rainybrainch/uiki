    設定雨域の設定

    ⚠ このページの他のスクリプトからも読み取れます。公共の端末では使用しないこと。

    GitHub → Fine-grained tokens
    Permissions: Gists (Read and Write) のみを選択

    Google Drive 連携（任意・v2.8 / 2026-05-16）

    API キー取得手順：① 新規プロジェクト作成 → ② Drive API を有効化 → ③ 認証情報 → API キー作成。

    ⚠ Vision 機能（自撮りランク評価・体組成計数値化・食事カロリー推定）には
    ① GitHub PAT（読雨書き込み用・上の欄）と ② Gemini API キー（下の欄）の両方が必要です。

    Vision AI 連携（v2.19 / 2026-05-17・必須・本機能の核）

    Drive の最新画像（自撮り／食事／体組成計）を AI が読み取り、ランク・カロリー・数値を抽出して読雨に投入する。
    Gemini（無料推奨）：Google AI Studio でキー作成・無料枠あり。
    Claude（任意・有料）：Anthropic Console でキー作成。重要な評価で精度優先したい時に。

    データ管理（v2.30-33 / 2026-05-17）

    読雨 Gist の中身と localStorage（タスク・砂のログ・設定）を JSON でバックアップできます。
